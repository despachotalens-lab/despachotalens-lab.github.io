Calendario de Escritorio

CalendarWidget es una aplicación de uso personal que muestra tu propio Google Calendar como un widget en el escritorio de Windows.

Aviso: esta aplicación no es un servicio público. Se conecta directamente, solo desde el ordenador de su propietario, con la API de Google Calendar mediante OAuth 2.0. No existe servidor intermedio ni se recogen datos de terceros.
